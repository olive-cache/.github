# Olive - Edit Video You Already Have

![Olive timeline with clips from footage the user owns](https://upload.wikimedia.org/wikipedia/commons/2/23/Olive_video_editor_Alpha_0.1.0_2019-10_1e3cf533-fr.png)

## Product Snapshot

Olive is a video editor for footage you shot or were allowed to use. You trim, order, and preview, then export a file that is separate from the originals. Nodes or effects, when you use them, sit on top of those clips. They do not create the picture. If the only way to get a frame is to break a lock, this is the wrong program.

Save the project beside the clips. If you move the videos and do not relink them, the timeline goes empty even though the files still exist. Keep the first project short: two clips and one cut. A long sequence can wait until that export plays from the first second to the last.

## Mount and Burn Toolkit

| Task | What you get |
|---|---|
| Timeline | Clips you already have, in an order you set |
| Markers | Points you can jump back to |
| Preview | Playback inside the editor |
| Cache | Temporary frames, not a substitute for the sources |
| Export | A new video file |
| Project | The file you reopen to recut |

The cache can be deleted when you need disk space. The camera originals cannot, until you are sure you will not recut.

## Deep Dive

Create the project in the folder with the media, not in a temporary path. Add two shots, trim the ends you do not want, and play the join. Listen for a missing voice. Export under a new name. Open that file outside Olive.

A cache that fills the disk is a reason to clear the cache, not a reason to delete the rushes. Effects that confuse the first hour can stay off. Olive does not download films, and it does not remove copy protection. A commercial track you do not have rights to is not a soundtrack just because it fits.

## Adoption Paths

Olive fits a personal recap or a short explainer made from recordings you created. It fits a project you can relink if you move the disk. It does not fit a locked disc, a film you do not have a file for, or a workflow that throws away the only camera copy the same day.

## Install Walkthrough

Prerequisites: Clips you may edit, and room for a project plus an export.

1. Install Olive and save a project next to the media.
2. Place two clips on the timeline and trim them.
3. Preview the cut, including the audio.
4. Export a new file. Do not overwrite the sources.
5. Play the export outside Olive. Keep the originals until that viewing is done.
